Form

Used for users to input or select information.

For example

  • Register an account
  • Log into the website
  • Enter name ane password
  • Participate in a survey
  • Submit contact info
Note: "hr" → horizontal rule, to create a break or visual divider.

There are some useful tags:

  1. form - create the entire form
  2. label - to tell the users what to input
  3. input - to input
  4. textarea - multi-line input
  5. select - drop down menu, to let the users to select form options
  6. button - submit or trigger an action
